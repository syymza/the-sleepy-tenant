1. Tea cup set down 2.mp3, TheHiraHira, 2019-02-21
   Porcelain teacup placed on ceramic saucer.

   https://cdn.freesound.org/previews/460/460241_9117851-hq.mp3
   Edit: 1.898-2.558 seconds; mono 24 kHz; gentle high/low-pass, edge fades,
   peak normalization before a quiet runtime gain. Used for ceramic contact.

2. plate on table, ventousawins, 2023-03-30
   Plate placed on wooden table.
   https://freesound.org/people/ventousawins/sounds/681421/
   https://cdn.freesound.org/previews/681/681421_14819331-hq.mp3
   Edit: 3.065-3.405 seconds; mono 24 kHz; high-pass 80 Hz, low-pass 1850 Hz,
   edge fades and peak normalization before a quiet runtime gain.
   Used as the damped ceramic-to-table contact family. In this scene only
   the mug lifts; the saucer remains table-supported, so it has no landing event.

3. CERMFric_Ceramic Saucer Dragged On Wood Surface 01_Kospak,
   bilginaslankospak, 2026-08-23
   https://freesound.org/people/bilginaslankospak/sounds/867581/
   https://cdn.freesound.org/previews/867/867581_3971939-hq.mp3
   Edit: 2.750-3.570 seconds; mono 24 kHz; high-pass 150 Hz, low-pass 2600 Hz;
   a 40 ms equal-power loop join, then quiet speed-dependent runtime gain.
   Used only while the saucer actually moves across the tabletop.

Bundled as PCM16 in foley.js; buffers are allocated only after Sound enable.

these contact or scraping sounds. Existing creature cues are unchanged. The separately reviewed Pearl purr is
documented in PURR-LICENSE.txt.
