# The Sleepy Tenant

A tiny creature lives in an oversized ceramic cup. Gently drag its saucer and it peeks out. Move too quickly and it retreats. Leave it alone and it checks on the world or settles into its cup.

[Play The Sleepy Tenant](https://syymza.github.io/the-sleepy-tenant/)

One scene, a few gentle gestures, and seven small reactions. Handcrafted Canvas art, warm matte ceramic, soft contact shadows and a compact, expressive tenant. The creature moves at fixed proportions, with arms that bend toward the rim and fingers that curl over it.

## Play

- Drag the mug body or painted handle to lift its little home, with the tenant riding inside. Place it on the table, or bring it near the saucer for a gentle return to its seat.
- Drag the saucer to slide it. It carries the mug only while the mug is seated on it.
- Stroke the visible head slowly for a sleepy response. A quick poke makes the tenant duck.
- Keyboard: Tab chooses the mug, saucer or pet. For the mug, Enter lifts/places and arrows move it. Arrows slide the selected saucer. Enter strokes the selected pet; Shift+Enter gives a quick poke. Home brings everyone back. Space pauses while a scene object is focused.
- **Sound off** enables optional contact sounds, a sleepy peeking murmur and retreat rustling. Gentle head strokes add the approved quiet real-cat purr, fading out when stroking stops; quick pokes never purr. The lifted mug does not scrape the table. **Sound on** mutes it again. Sound starts off on every visit.
- Pause stops motion and sound. Reduced-motion preferences remove decorative movement.

Cup-to-saucer landing uses a recorded ceramic clink; cup-to-table contact is shorter and damped. A finite cup descent supplies the contact velocity for a modest, capped change in level. One contact event and a cooldown prevent chatter. Recorded scraping follows actual saucer motion and stops at rest. The saucer remains table-supported: upward drags move it across the tabletop, so there is no invented saucer landing sound. Reset and cancelled placements are quiet.

Picking follows the painted shapes, including the handle opening. Empty space has a neutral cursor. Movement and tilt are constrained; landing is deliberately forgiving rather than a free-body simulation. Desktop space is used for movement without simply scaling up the artwork. Resizing ends an active gesture before recalculating coordinates.

No background music, activation chime, accounts, analytics, external assets or services. The experience works offline. Sound uses local Web Audio synthesis for creature cues plus bundled CC0 recordings for contact, scraping and the reviewed Pearl purr and unlocks through a user gesture. After an interruption, a new scene gesture resumes it; muted audio stays muted.

## Run locally

Open `index.html` directly, or with Node.js 22 or later:

```sh
npm ci
npm start
```

Open `http://127.0.0.1:4173`. Development dependencies are only used for tests. The playable site needs no installation or build step.

## Check and build

```sh
npm ci
npx playwright install --with-deps chromium webkit
npm run check
npm test
npm run build
```

Checks cover independent lifting, table placement, docking, conditional carrying, pet stroke/poke, shape picking, keyboard access, resize/orientation cancellation, bounded layouts and audio lifecycle. Browser checks use real gestures in Chromium and WebKit, including native Chromium touch emulation. Audio checks measure real Web Audio signal peaks and silence. Browser verification opts into a read-only scene snapshot with `?inspect`; it is absent during ordinary play.

`npm run build` copies the runtime files and the bundled purr, Foley and provenance assets into `_site/`, with `.nojekyll` and a `version.json` commit/hash manifest. GitHub Pages deploys this directory after changes reach `main`. Local recordings, screenshots and QA artifacts are ignored and excluded from deployment.

Mobile testing uses browser emulation; physical iPhone hardware and a full assistive-technology audit are outside the automated checks. Web Audio output levels are measured; hardware volume and speaker character vary by device.

## Source

```text
index.html       accessible scene and controls
style.css        responsive layout and material palette
app.js           gesture, state and procedural drawing
audio.js         opt-in recording playback, creature cues and audio lifecycle
assets/          bundled CC0 recordings and provenance
tests/          sound and browser regression checks
```

Runtime art is generated by code. The quiet purr is the reviewed audition B, a four-second edit of [Sadiquecat's Female cat purr](https://freesound.org/people/Sadiquecat/sounds/695630/). [Purr provenance](assets/PURR-LICENSE.txt) and [Foley provenance](assets/FOLEY-LICENSE.txt) record sources, CC0 licenses, edits and byte hashes. Recordings are embedded in local data scripts for direct `file://` playback. Code is MIT licensed; the recordings are CC0. Future changes go through pull requests and passing checks. Revert a merged change and redeploy to roll it back.
